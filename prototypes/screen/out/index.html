bwmusic — screen prototype (Bangle.js 2 emulator, 176×176 @2×)

A — Pebble action bar

Right action bar: tap top = vol+, middle = play/pause, bottom = vol−. Swipe ←/→ = next/prev. BTN = exit.

B — Gesture-only, big type

No buttons on screen. Tap anywhere = play/pause. Swipe ←/→ = next/prev. Swipe ↑/↓ = volume. BTN = exit.

C — Control row

Bottom row of 3 big buttons: prev, play/pause, next. Swipe ↑/↓ = volume. BTN = exit.
